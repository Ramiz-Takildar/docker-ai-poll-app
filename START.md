# 🚀 START HERE

## One-Command Startup

### Linux/macOS Users
```bash
chmod +x run.sh
./run.sh
```

### Windows Users
```cmd
run.bat
```

### Any OS (Python)
```bash
python run.py
```

---

## ✨ That's It!

Your application will be running at **http://localhost:5000**
